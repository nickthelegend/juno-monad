# Juno on Monad 1.1.0

The Monad port brought up to the Solana app's 1.1.0, plus what Monad needed.

## What is in it

- **Exact-out buys.** `buyExactOut` buys an exact number of tokens for at most
  a stated cost and refunds the rest. The trade sheet's token chip switches
  between "spend" and "get exactly".
- **Trading after a Uniswap v2 graduation.** `JunoSwapRouter` trades a
  graduated coin against its pair in one transaction; the fills are recorded
  and indexed.
- **Privy on iOS and Android.** Email sign-in makes an embedded EVM wallet that
  signs every launch, trade and claim; the device key remains the default.
- From the Solana 1.1.0: the launch log, the trade receipt, the NAV band
  warning, the depth chart, Pre-IPO logos, retries on busy RPC reads, curve
  presets limited to their measured ranges.

## Downloads

| File | What |
|---|---|
| `juno-monad-1.1.0-arm64.apk` | Android, arm64. Talks to an API at `http://10.0.2.2:3100` — the host machine, from the Android emulator |
| `juno-monad-1.1.0-ios-simulator.zip` | iOS Simulator (Apple silicon). Talks to an API at `http://localhost:3100` |
| `SHA256SUMS` | Checksums of both |

Both builds point at a **local** API because there is no hosted one yet. Run
the stack as the README's *Run it* says (API on port 3100), then:

```bash
adb install juno-monad-1.1.0-arm64.apk
```

```bash
unzip juno-monad-1.1.0-ios-simulator.zip && xcrun simctl install booted Juno.app
```

The APK is signed with the debug key: installable, not uploadable to Play.
